# Asset sources

- The scenario and workflow illustrations in [assets](assets/) are SatMend project figures supplied by the authors. Their image contents are preserved.
- [The example configuration and contact calendar](examples/) were written for this release. They describe a synthetic three-satellite scenario.
- The simulator and reference planner use the Python standard library at runtime. The package is built with setuptools and no third-party code is vendored.
